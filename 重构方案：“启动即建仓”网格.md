```
async def _place_initial_orders(self):
    """
    Places 'open' orders for all grid levels.
    Orders placed on the 'wrong' side of the market price are expected to
    fill immediately, establishing the initial positions.
    """
    print("Placing initial orders to establish grid positions...")

    for price, level in self.grid_levels.items():
        if level.status == "AVAILABLE":
            try:
                order_amount_coin = self.config.order_amount_usdt / price
                
                # --- KEY MODIFICATION: REMOVED postOnly and price checks ---
                params = {
                    'positionSide': 'LONG' if self.side == 'long' else 'SHORT'
                }

                if self.side == "long":
                    order = await self.exchange.create_limit_buy_order(order_amount_coin, price, params)
                else: # short strategy
                    order = await self.exchange.create_limit_sell_order(order_amount_coin, price, params)
                
                # We assume the order is pending. The watch_orders loop will handle
                # immediate fills by transitioning the state to POSITION_HELD.
                level.open_order_id = order['id']
                level.status = "ORDER_PENDING"
                print(f"Submitted OPEN {'LONG' if self.side == 'long' else 'SHORT'} order {order['id']} at {price}")

            except Exception as e:
                # Price protection errors might still occur if grid is too wide.
                if 'limit price can\'t be higher' in str(e).lower() or 'limit price can\'t be lower' in str(e).lower():
                    print(f"Skipping order at {price}: Price outside exchange limits.")
                else:
                    print(f"Error placing initial order at {price}: {e}")
    
```

### **总结：修改后的效果**

完成以上“删除”和“修改/新增”操作后，机器人将具备以下行为特征：

1. **启动即建仓**: 在 initialize_grid 期间，策略会向交易所提交所有网格点的开仓限价单。
2. **立即成交**: 所有挂在当前市价“错误”一侧的订单（例如，做多时高于市价的买单）将被交易所立即撮合成交。
3. **事件处理**: _watch_orders 循环会接收到这些即时成交的事件。
4. **挂出平仓单**: handle_filled_order 会为每一笔成交的初始仓位，挂上一个对应的平仓单。
5. **缓冲延时**: asyncio.sleep(3) 提供了一个缓冲期，让上述的事件处理流程有时间完成。
6. **正常运行**: 初始化完成后，策略进入正常的“单兵接力网格”运行模式，但初始状态是一个多级的持仓组合，而不是0持仓。
